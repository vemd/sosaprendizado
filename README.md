# SosAprendizado · apresentação

Landing page pública da SosAprendizado. O código da aplicação e as credenciais ficam fora deste repositório.

Publicação estática no GitHub Pages, a partir da raiz do ramo main. O subdomínio preparado para esta página é conhece.sosaprendizado.com. O domínio principal sosaprendizado.com destina-se à aplicação web.

A demonstração de Matemática funciona apenas no navegador e não envia respostas nem cria um perfil. A página não instala ferramentas de publicidade ou análise.

Os textos legais identificados como preliminares dependem da confirmação do responsável e das condições de lançamento.
